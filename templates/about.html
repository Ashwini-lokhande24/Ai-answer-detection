About this project

AI-Generated Student Answer Detection uses NLP and Deep Learning to estimate whether a written answer reads as human-written or AI-generated, based on linguistic patterns in the text.

How it works

Submitted text is cleaned and tokenized, then passed through a Bidirectional LSTM model trained on a labeled dataset of human- and AI-written essays. The model outputs a confidence score rather than a definitive judgment.

Model performance

  • Trained on ~27,000 essays
  • 98.57% accuracy on held-out test data
  • Balanced precision and recall across both classes

A note on limitations

This model is trained specifically on essay-style writing. It is not reliable on very short text, conversational prompts, or text unlike its training data — and its output should be read as a pattern-based estimate, not proof of authorship.
