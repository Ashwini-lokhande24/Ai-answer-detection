# AI-Generated Student Answer Detection

A deep learning system that detects whether a student's written essay was generated by AI or written by a human. Built using a Bi-LSTM neural network and deployed as a Flask web app.

## 📌 Overview

With generative AI tools becoming widely accessible, distinguishing AI-generated academic writing from human-written work has become a real challenge for educators. This project builds an NLP-based classifier that predicts whether a given essay/answer was written by a human or generated by an AI model, and serves the prediction through a simple web interface.

## 🎯 Key Results

| Metric | Value |
|---|---|
| **Test Accuracy** | **98.57%** |
| Precision/Recall | Balanced across both classes |
| Dataset size | 29,145 essays |
| Class distribution | ~59% / 41% (handled via class weighting) |
| Sequence length (padded) | 421 tokens |
| Vocabulary size | 20,000 words |

---

## 🧠 Model Architecture

- **Embedding Layer** — output_dim = 60 (tuned down from 100 to reduce overfitting)
- **Bi-LSTM Layer** — 64 units
- **Dropout** — 0.4
- **Dense Layer** — Sigmoid activation for binary classification

**Training strategy:**
- Class weighting (`balanced`) used instead of SMOTE/undersampling to handle class imbalance
- EarlyStopping (`monitor='val_loss'`, `patience=3`, `restore_best_weights=True`) to prevent overfitting
- Trained on Google Colab (GPU runtime), with Google Drive used for persistent storage

## 🚀 How to Run Locally

1. **Clone the repository**
   ```

   cd Ai-answer-detection
   ```


   ```
   python app.py
   ```

   ```
   http://127.0.0.1:5000
   ```
